# 念念 · AI 分层复习规划器

一款本地运行、单人使用的 Web 复习工具：把学习笔记一键解析成知识点，按改良版艾宾浩斯遗忘曲线自动安排复习，并通过「选择题 → 填空题 → 简答题」的分层出题逐步巩固记忆。

![念念学习仪表盘](assets/dashboard.png)

## 功能一览

- **笔记录入（复习块模式）**：上传图片 / PDF / 粘贴文本 → AI 总结全文供确认识别是否正确 → AI 结合整篇内容提炼复习要点（可自由编辑，支持代码示例）→ 整篇笔记保存为一个「复习块」，统一安排复习
- **知识点管理**：新建、编辑、删除、拆分、合并，自定义学科标签层级，自定义题型流程；复习块的 AI 总结与要点可随时修改
- **代码高亮**：笔记、复习要点与题目中的代码（C / C++ / Go / Java / Python / JavaScript / SQL / Bash 等）自动语法高亮
- **AI 接口自配**：支持任意 OpenAI 兼容接口（默认 DeepSeek），请求体模板可自由编辑，API Key 加密存储
- **智能调度**：空闲时段（每日 / 每 2 天 / 每 3 天循环）、标准艾宾浩斯间隔、按掌握度动态调节复习周期、任务过载时优先安排临近遗忘临界点的知识点
- **分层出题（选择题优先）**：按复习块的每个要点出题，选择题最多、填空题其次、简答题最少；简答题使用与笔记原文一致的语言提问并引用原文代码示例；支持选择题 → 填空题 → 简答题的分层流程与自定义题量；无 AI 配置时自动降级为本地出题
- **答题闭环**：逐题作答，答完立即标注对错（正确绿色✓ / 错误红色✗并标出正确选项），题目下方即时给出知识点简介；全部答完后统一批改，可在逐题回顾中查看答案（含代码高亮），并更新掌握度与下次复习时间
- **错题本**：作答失误自动收纳，支持移除与导出
- **资料导出**：笔记导出（Markdown）、题目导出（文本）
- **仪表盘**：今日任务、掌握度、未来 7 天复习计划一目了然

## 技术栈

- 前端：原生 JavaScript + Tailwind CSS（本地内置，无需联网）
- 后端：Node.js + Express
- 数据库：Node 内置 SQLite（`node:sqlite`，Node 22.5+），共 6 张业务表
- 加密：AES-256-GCM 加密存储 API Key

## 运行方法

这是一个**本地运行的单人 Web 应用**：用浏览器打开，数据和音乐都存在你自己电脑上，不依赖外网。

### 1. 确认 Node 环境
需要 **Node.js 22.5 或更高版本**（用了新版内置 SQLite）。
命令行输入 `node -v`，显示 `v22.x` 或更高即可；没有就去 [nodejs.org](https://nodejs.org) 装一个。

### 2. 安装依赖（只需一次）
在**项目文件夹**里打开命令行，执行：
```bash
npm install        # 或 pnpm install
```
> 国内网络慢的话可加镜像加速：`npm install --registry=https://registry.npmmirror.com`

### 3. 启动
```bash
npm start          # 开发时可改用 npm run dev（文件改动自动重启）
```
看到提示后，用浏览器打开 **http://localhost:3000** 即可使用。

### 4. 首次使用（4 步，跟着界面走）
1. **设置**：填大模型接口地址和 API Key，点「测试连接」（留空也能用，出题会降级为本地出题模式）
2. **笔记录入**：上传笔记或粘贴文本 → 确认 AI 总结 → 让 AI 提炼要点 → 保存为「复习块」
3. **时间安排**：设置每天可复习的时间段
4. **开始复习**：完成今日任务，逐题作答

> 图标：`localhost:3000` 就是应用在本机的地址，手机同网段也能通过局域网 IP 访问。

## 图片识别（OCR）

上传笔记照片时，应用会先用本地 OCR 把图片变成文字，再交给 AI 解析（DeepSeek 等纯文字模型也能用）。需要 Python 3.8+：

```bash
pip install rapidocr-onnxruntime
```

如果 Python 不在系统路径中，启动时指定：

```bash
# Windows PowerShell
$env:OCR_PYTHON = "C:\path\to\python.exe"
npm start
```

未安装 OCR 时，上传图片会给出明确提示；也可以改用手动粘贴文字，或在设置页切换到「视觉模型」模板直接把图片发给支持图片的大模型。

## 目录结构

```
review-planner/
├── server/            # 后端
│   ├── index.js       # Express 入口
│   ├── db.js          # SQLite 建表与初始化（6 张表）
│   ├── crypto.js      # API Key 加密
│   ├── ai.js          # AI 调用与模板渲染（含离线降级）
│   ├── ebbinghaus.js  # 艾宾浩斯调度引擎
│   └── routes/        # 各业务接口
├── public/            # 前端页面（七个页面 + 公共脚本）
├── data/              # 数据库与上传文件（运行时生成）
└── package.json
```
